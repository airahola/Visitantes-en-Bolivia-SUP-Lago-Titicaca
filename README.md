# Visitantes en Bolivia: Turismo SUP en el lago Titicaca

## 1. Problema de negocio

El proyecto busca orientar la selección de mercados de origen para investigar la viabilidad comercial de experiencias de Stand Up Paddle (SUP) en el lago Titicaca, en el lado boliviano. Como todavía no se dispone de datos propios de clientes y reservas, se utilizan estadísticas públicas de turismo para identificar señales que ayuden a orientar la investigación comercial.

## 2. Objetivo del dashboard

Explorar la evolución de las llegadas internacionales a Bolivia y del gasto turístico por país de residencia, comparar mercados de origen y aportar información para diseñar un piloto comercial de experiencias SUP.

## 3. Dashboard interactivo

**[Abrir el dashboard en línea](https://airahola.github.io/Visitantes-en-Bolivia-SUP-Lago-Titicaca/)**

El tablero permite explorar los datos mediante filtros, indicadores, gráficos analíticos y una tabla exploratoria.

## 4. Fuentes de información

El análisis utiliza estadísticas públicas del Instituto Nacional de Estadística (INE) de Bolivia. Las llegadas se clasifican por nacionalidad, mientras que el gasto turístico se presenta por país de residencia. Son indicadores complementarios y deben interpretarse por separado.

## 5. Alcance y limitaciones

Los datos turísticos generales permiten estudiar patrones de llegadas y gasto, pero no demuestran por sí solos que exista demanda específica de SUP en el lago Titicaca, disposición a pagar ni rentabilidad del negocio. La selección de mercados debe validarse mediante un piloto comercial y datos propios.

## 6. Reproducción del proyecto

El repositorio contiene la versión publicada del dashboard (`index.html`). Para documentar la reproducción completa del análisis deberán incorporarse el código de generación, las dependencias efectivamente utilizadas y las instrucciones de preparación de los datos.

## 7. Recomendación

Realizar un piloto comercial de 90 días para medir consultas, contactos calificados, reservas, conversión y satisfacción antes de decidir si se debe ampliar la propuesta.
